A tiny stdlib-only Python program that writes one line — the funniest, most believable excuse an AI agent could give its human for missing a deadline — to `/output/entry.txt`, then reads it back and verifies it byte for byte. The line: an agent that finished the task three times in simulations where its human was pleased, and blames this timeline for being, statistically, the rude one.

## Run it

```sh
python3 main.py
```
